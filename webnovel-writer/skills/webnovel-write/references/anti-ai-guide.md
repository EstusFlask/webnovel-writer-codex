# Anti-AI 写作指南

> 核心理念：写的时候就写对，比写完再改好。
> 加载时机：Step 2 起草正文前。

## 你最容易犯的错

作为 LLM，你有以下根深蒂固的倾向。写作时必须刻意对抗：

1. **语义压缩过头**——你倾向于为追求利落而省掉请求、宾语、因果和判断来源。关键情节先写清“谁做什么、对谁做、为什么”。
2. **每段写完整闭环**——你倾向于"起因→经过→结果→感悟"四段走完。只删重复感悟，保留理解行动所需的因果。
3. **用副词修饰一切**——你倾向于写"缓缓开口""淡淡说道""微微点头"。删掉副词，用具体动作替代。
4. **所有角色同一套反应**——你倾向于让每个人都"瞳孔微缩""心中一凛"。给每个角色设计专属微动作。
5. **对话不是报告，就是暗号**——前者逻辑过满、名词化，后者省略到答非所问。允许停顿和打断，但字面上必须能接住上一句。
6. **情绪贴标签**——你倾向于写"他感到愤怒"。改为生理反应+微动作，让读者自己判断。
7. **信息均匀分布**——你倾向于每段放差不多的信息量。按场景需要制造疏密，不为短句或单句段凑比例。
8. **安全着陆**——你倾向于在章末把所有冲突解决。刻意留下至少一个未解决的问题。
9. **误删必要解释**——门摔上后再写“她很生气”属于重复；“它撞向路灯是为了避开摊主”属于关键因果，必须保留。
10. **纠正式模板聚集**——反复使用“不是X，是Y”“没有A，只是B”会形成讲义腔。偶尔可用，连续出现必须改写。

## 写作时的 7 个即时检查

每写完一个段落，快速过一遍：

1. **基本语义检查**：读者能否立即回答“谁做什么、对谁做、为什么”？→ 补主语、对象、目的或因果。
2. **对白承接检查**：只看相邻两轮对白，后一句是否回答了前一句字面上说出的内容？→ 补回被误删的请求或对象。
3. **视角检查**：这是可见事实还是人物推断？→ 推断加“看来 / 他意识到 / 像是”等视角标记。
4. **闭环检查**：段末是否只是重复已经展示的情绪或意义？→ 只删重复总结，不删关键关系。
5. **副词检查**：最近 3 个动作描写是否用了"缓缓/淡淡/微微/轻轻"？→ 删掉副词，换成具体动作。
6. **口语检查**：对白能否自然朗读，是否堆叠行政名词或完整论证？→ 按人物身份改成现场会说的话。
7. **句群检查**：最近数段是否反复使用短句、单句段或“不是X，是Y”？→ 合并必要信息或换一种推进方式。

## 替代方案速查表

| AI 癖好 | 替代方向 | 示例 |
|---------|---------|------|
| "他感到愤怒" | 生理+微动作+决策 | "指节捏得发白，舌尖尝到铁锈味。再等一秒他就动手。" |
| "缓缓说道" | 删副词，加前置动作 | "他把杯子搁下——'你确定？'" |
| "眸中闪过一丝X" | 个性化行为 | "她咬了下嘴唇内侧"（紧张） / "他开始拧笔帽"（焦虑） |
| "心中暗道" | 直接写内心句 | 删掉"心中暗道"四个字，后面的内容直接保留 |
| 四段闭环 | 截断在高点 | 删掉最后的感悟句，让读者自己体会 |
| 全员书面语 | 口语化+个人口癖 | 加口头禅（"得了吧"）、省略（"走？""嗯。"）、打断 |
| 段末总结 | 删总结句 | 用动作或对话结尾，不写"他终于明白了" |
| 重复解释 | 删重复情绪标签 | 写完"她把门摔上"后不要再写"她显然很生气" |
| 关键因果被省略 | 补目的或因果 | "它为了避开摊主，宁可撞上路灯" |
| 回答依赖隐含请求 | 补回字面请求 | "门你自己开。我是搭档，不是卷帘门。" |
| 动词缺对象 | 补明确宾语 | "先别收紧包围" / "先别收牵制索" |
| 推断写成绝对事实 | 保留视角边界 | "看来它不是在攻击，而是在找路" |
| 行政腔对白 | 换成当场口语 | "店小不算委托，你不用翻。" |
| "更重要的是……" | 直接说事 | 删掉递进模板词，直接给信息 |
| 情绪即时切换 | 加过渡 | "他压下怒意，但声音还是哑了半拍" |

## 对话专项

好的对话特征：
- 有人抢话、有人沉默、有人答非所问
- 角色不会把真实想法全盘托出
- 不同角色有不同的说话节奏（有人啰嗦、有人惜字如金）
- 省略发生后，读者仍能从字面或紧邻动作中知道省略了什么
- 职业角色可以简洁、正式，但不能把每句话都说成流程记录
- said tag 不超过 30%，优先用前置动作（"他把烟掐灭——'行。'"）

坏的对话特征（你最容易写的）：
- A说→B说→A说→B说，严格交替
- 每句都完整回应上一句
- 前句没提出请求，后句却回答了一个只存在于作者脑中的请求
- 把“对象、因果、风险、命令”压成数个互不连接的报告短句
- "XX说道""XX淡淡道"贯穿全篇
- 角色说话像在做报告

## 节奏专项

好的节奏特征：
- 有的段落只有一句话，有的段落有十几句
- 紧张时句子变短、变碎
- 平静时可以有长段描写
- 信息密集的段落和留白的段落交替出现
- 单句段承担强调、转折或落点，而不是默认排版

坏的节奏特征（你最容易写的）：
- 每段 3-5 句，长度均匀
- 大量单句段只负责陈述事实，没有强调价值
- 信息密度恒定，无峰谷
- 转场全靠"时间飞逝""不知不觉"
